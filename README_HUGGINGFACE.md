# 🗑️ Smart Waste Sorter

An AI-powered waste classification system built with YOLOv8 and Gradio.

## 🎯 Features

- **Real-time Classification:** Upload images to classify waste into 4 categories
- **Categories:**
  - 🔴 Plastic (bottles, containers, packaging)
  - 🟢 Paper (cardboard, newspapers, magazines)
  - 🔵 Metal (cans, aluminum foil)
  - 🟠 Organic (food waste, fruits, vegetables)
- **Visual Results:** Bounding boxes with confidence scores
- **Statistics:** Category counts and distribution

## 🚀 How to Use

1. Upload an image containing waste items
2. Click "Classify Waste"
3. View results with bounding boxes and statistics

## 🛠️ Technology

- **YOLOv8n:** Fast and accurate object detection
- **Gradio:** Interactive web interface
- **Intelligent Mapping:** 80 COCO classes mapped to 4 waste categories
